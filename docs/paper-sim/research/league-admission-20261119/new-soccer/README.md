## 样本与计算口径

| 赛事 | 初始历史 | 调参日期与场次 | 留出比赛日期 | 纳入阶段 |
|---|---|---|---|---|
| 巴西甲 | 2022–2023，760 场 | 2024–2025，760 场 | 2026-01-28 至 2026-11-18 | 常规联赛 |
| 乌拉圭甲 | 2023–2024，591 场 | 2025，296 场 | 2026-02-06 至 2026-11-17 | Apertura、Torneo Intermedio、Clausura |
| 乌兹别克超 | 2023–2024，364 场 | 2025，240 场 | 2026-02-27 至 2026-11-14 | 常规联赛 |
| 哥伦比亚乙 | 2023–2024，605 场 | 2025，303 场 | 2026-01-23 至 2026-11-16 | Apertura、Clausura，含两阶段四队小组 |
| 东盟俱乐部锦标赛 | 2024/25，30 场 | 2025-07 至 2025-12，18 场 | 2026-01-28 至 2026-11-18 | 小组赛 |

比分为常规时间加补时。来源标明加时、点球决胜、判罚或未赛的行被排除。比赛数据截止到 2026-11-19 00:00 UTC+01 前。每场预测的截点为开球所属档案日的前一天 23:59 UTC+01，只用至少早两个档案日的比分更新状态。留出期内已比赛果按同样延迟进入后续比赛状态，参数保持冻结。优化和基线都只依赖过往比分、主客身份和比赛日期。

固定基线以 300 天半衰期加权，以 14 场等效数据收缩球队进攻和防守，强度指数 0.75，Dixon–Coles 校正 −0.08。另报告纯联赛平均进球强度的泊松对照。每联赛在早期样本分别选出 1X2 和 O/U 2.5 的候选参数，Brier 定序，对数损失用于打破平局。2.5 的一套参数也用于 1.5、3.5、4.5 和 5.5 球线。

BetExplorer 提供逐场比分、开球和逐博彩公司报价。开球同时匹配页面结构化时间与档案显示的固定 UTC+01 时间。盘口按比赛 ID、整个常规时间、市场和精确半球线匹配。每个博彩公司需提供完整的两边或三边，每边时间都严格早于开球且距离开球不超过 24 小时。对每家分别以倒数归一化去水，再等权平均。档案只给各选项的最后一条报价及其时间，邻近开球时刻的盘口用于概率对照。Polymarket 自身的历史可成交价格、交易费和盘口深度需要单独验证。 [市场样例](https://www.betexplorer.com/match-odds/AaNEdxnS/1/1x2/odds/?lang=en) · [大小球样例](https://www.betexplorer.com/match-odds/xIH415CT/1/ou/odds/?lang=en)

差值按“比较对象的 Brier 减优化模型的 Brier”计算，正值代表优化表现更好。区间在同场同线配对的前提下按档案日的 ISO 周做 2,000 次区块重采样，未做跨联赛或多盘口线的显著性校正。

## 明细与复跑

- [逐场逐线](holdout_predictions.csv) 含 6,900 行、预测截点、常规时间比分、每种模型与盘口概率、赔率来源、符合条件的博彩公司数和报价时间范围。
- [综合指标](metrics.csv) 含配对样本与全赛果样本的覆盖数、Brier、对数损失、命中率和区间。 [胜/平/负与大/小分项](outcome_metrics.csv) 含观察比例、各预测平均概率和对应的二分类 Brier。
- [冻结参数](frozen_parameters.json) 记录每联赛入模历史摘要和配置。 [全部调参候选](tuning.csv) 保存早期数据结果。 [来源和排除统计](frozen-inputs/fixture_sources.json) 保存每季每阶段页面。
- [回测实现](backtest.py) 和 [历史档案采集](collect.py) 读取资料并生成表格。 [完整校验记录](audit.json) 和 [SHA-256 清单](MANIFEST.sha256) 记录归档验证。

在此目录下用 Python 3.12、`lxml` 和 `requests`，可离线从冻结赛果及逐腿盘口重新产生全部结果。

```bash
(
set -e
replay_dir=$(mktemp -d)
python3 -B backtest.py freeze --data frozen-inputs --output "$replay_dir"
python3 -B backtest.py score --data frozen-inputs --output "$replay_dir"
for file in frozen_parameters.json tuning.csv holdout_predictions.csv metrics.csv metrics.json outcome_metrics.csv; do
  cmp "$file" "$replay_dir/$file"
done
sha256sum -c MANIFEST.sha256
)
```
