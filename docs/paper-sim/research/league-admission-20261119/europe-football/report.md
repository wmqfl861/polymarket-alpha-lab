# 欧洲国内足球的赛前价格复核

以项目原十变体模型和按历史训练窗选参的再校准模型，核对 Polymarket 开球前 60 分钟的同场合约。胜平负使用三个方向的 Yes 价格，按总和归一化。2.5 球盘口使用 Over 代币。所有结果都用常规 90 分钟及补时比分计分。

原六联赛有 360 场配对预测。法甲另补 72 场预测。432 场中有 61 场的模型信息截止晚于本研究的取价时点，1 场意甲因双方开球时间记录不同剔除，1 场荷甲的胜平负三份价格相隔超过 5 分钟。最终胜平负分析 369 场，2.5 球分析 370 场。

英冠和荷甲按既有授权继续对总进球类做逐场模拟筛选。两条胜平负策略的再校准版本在这批历史市场上均未优于市场。英超大小 2.5 优化方向值得留作前向对照，该样本相差 −0.02408，95% 区间上界为 +0.01026。只有七个比赛轮次，且本研究使用归档赛果与报价。

法甲旧样本因为首轮雷恩与巴黎主客记录颠倒而没有完整可回放轮次。根据 ESPN、FotMob 的主客、开球和完赛比分重新核对，用 FotMob 全场 xG 0.87 和 2.16 恢复该场。由此获得 8 个完整测试轮次和 72 场预测，65 场符合取价时点。法甲补充仅进入本次研究副本。 [FotMob 比赛](https://www.fotmob.com/matches/paris-saint-germain-vs-rennes/37imvq#5803105) · [ESPN 比赛](https://www.espn.com/soccer/match/_/gameId/401876487)

这些历史价格只有时间戳和单项价格。模型输入里的 xG 缺最初发布时间与修订历史，订单簿深度、全量扫描候选和前向盈亏也未进入本研究。各项拟合对比赛结果的评分与净回报分别评价。

在本目录用 Python 3.12 和 requests 从已核对输入离线重算配对差值和区间。

```bash
(
set -e
replay_dir=$(mktemp -d)
cp compare.py comparison-inputs.json.gz "$replay_dir/"
python3 -B "$replay_dir/compare.py" score
cmp summary.json "$replay_dir/summary.json"
)
```

研究服务器留存原 WP-P4 逐场档案、法甲 xG 输入和公开接口的采集缓存。服务器上的重建顺序为 `python3 france_replay.py`、`python3 compare.py fetch`、`python3 compare.py score`，也需要原审核工作树和公开接口。
